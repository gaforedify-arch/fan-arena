# Quiz / Admin (roaster vs roster)

## Quiz (what was added in UI)
- **Quiz tab** on the fan match screen where users answer quiz questions to earn XP.
- Admin can add quiz questions (separate from predictions).

## What “roaster/roster” means in the Admin
In this project, **roster** refers to the list of players under a team.
- **Teams tab roster**: a team’s saved players (persistent for that club).
- **Match squad**: the subset of players who are participating in the *current match* (fans only see/vote on this match squad).
